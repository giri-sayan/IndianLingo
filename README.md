# IndianLingo 🇮🇳

A vibrant, gamified Duolingo-style web application for learning Indian languages, featuring interactive lessons, Akshara (script) writing practice, cultural stories, and comprehensive courses.

## ✨ Features

- **9 Indian Languages**: Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, and Punjabi.
- **Gamified Lesson Paths**: Multi-unit curriculum with interactive lessons, vocabulary, translation, matching pairs, and speaking exercises.
- **Akshara Script Trainer**: Practice reading, recognizing, and tracing native scripts with stroke orders and transliteration.
- **Cultural Stories**: Immersive bite-sized folklore and cultural tales with integrated vocabulary quizzes.
- **Gamification & Motivation**:
  - Heart / Lives system
  - Daily streaks & XP tracking
  - Indian Rupee Coins & Gems shop
  - League Leaderboards & Daily Quests
  - Interactive Tiger Mascot ("Veer") with animated expressions and contextual reactions
- **Text-to-Speech**: Native audio pronunciation support using Web Speech API.

## 🚀 Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React** (icons)
- **Canvas Confetti** (celebration animations)

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/giri-sayan/IndianLingo.git

# Navigate to the project directory
cd IndianLingo

# Install dependencies
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Run Course Verification Tests
```bash
npm test
```
